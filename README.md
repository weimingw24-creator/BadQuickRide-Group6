# QuickRide Technical Spike 1

This repository contains the starter solution for the QuickRide Technical Spike 1 lab.

## Projects

- `QuickRide/` - Console application starter
- `QuickRide.Tests/` - xUnit test project
- `BadQuickRide.sln` - Visual Studio solution file

## Build

```bash
dotnet restore
dotnet build
```

## Test

```bash
dotnet test
```

## Run

```bash
dotnet run --project QuickRide
```
